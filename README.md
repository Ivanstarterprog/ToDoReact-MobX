# To Do List React

## О проекте

### Описание

Данный проект представляет из себя небольшое учебное приложения типа ToDo, переписанное с использованием библиотеки React. В этой версии проекта добавляется библиотека MobX, а так же дополнительная функциональность по работе с задачами

### Использования проекта

Для того чтобы открыть проект нужно выполнить команду "npm run dev"
